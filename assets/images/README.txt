TAMBAH GAMBAR TANPA MENGUBAH KODE

1. Bendera: simpan sebagai flags/{id}.webp, contoh flags/id.webp.
2. Gambar negara: simpan sebagai countries/{id}.webp, contoh countries/id.webp.
3. Tempat: simpan di places/, lalu isi field image pada countries.json.
4. Makanan: simpan di foods/, lalu isi field image pada countries.json.

Gunakan WebP lokal, bukan URL. Jika file belum ada, aplikasi otomatis menampilkan emoji bendera atau placeholder dan tidak mengalami error.
